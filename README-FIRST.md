# Before you start

This is a very preliminary early-alpha release of Brainana Target. We are sharing it with a small group of testers who want to explore the ideas and tell us what is useful and what is not.

Start with the bundled macaque demo and Demo tutorials. Expect bugs and unfinished workflows. The app has not been validated for surgical decisions.

Download the installer for your operating system from https://github.com/brainana/brainana-target/releases. The source ZIP is for developers; the full release ZIP includes all platform downloads and documentation.

Please report bugs or feedback at https://github.com/brainana/brainana-target/issues/new/choose, including your version and operating system. See README.md for installation and first-launch details.
