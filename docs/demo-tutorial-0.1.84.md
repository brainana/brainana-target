# Image tutorial in the normal planner (0.1.84)

The tutorial now boots the actual planner workspace inside the isolated demo document. It retains the normal navigation, Load images inspector, viewer proportions, toolbars, image dialogs and 3D controls. Instructions live in a movable floating window, like the existing guided tutorial. The separate tutorial-specific viewer layout and compact replacement image dialog have been removed.

The Images and display section has eight steps: check loaded images; switch MRI/CT; navigate slices; adjust brightness/contrast; blend MRI/CT; adjust CT opacity in slices; change slice layout; and rotate, translate or adjust opacity of the 3D brain. Every operational step offers guided practice. The introductory step explains the bundled images and their provenance. Wording identifies actual controls and the images to inspect.

Slice CT opacity and 3D brain opacity are separate exercises. A reproduction of the previous version confirmed that changing CT opacity from 0 to 1 changed tens of thousands of slice pixels; the old exercise made its relationship to the separate 3D brain unclear. The revised instructions name the affected viewer, highlight the normal control, and read current effective CT opacity from the renderer. The 3D exercise reads and adjusts the normal Brain opacity control separately. The revised native regression measures substantial anatomical pixel changes for both exercises rather than checking only input values.

The tutorial uses the ordinary planner state/render pipeline and normal image controls. Only the active exercise's edits are allowed. A project mutation check limits image selection, intensity windows, blending and CT opacity to their respective steps. Other controls remain visible but unavailable. View-only gestures, camera controls and movement of floating windows remain available. The image dropdown limits practice to the supplied reference MRI and CT. Reset, Show me, Previous/Next and the step slider restore complete example states. Live display feedback waits for image synchronization and ignores feedback from cancelled steps.

The original user workspace still remains loaded behind the modal demo document. The planner's tutorial-session flag skips opening project recovery storage, suppresses normal project autosaves and portable saves, and leaves settings/layout persistence controls unavailable. Only tutorial progress is saved separately. Existing projects, pending drafts, undo history, viewer state and the separate Guided tutorial are preserved.

Verification covers normal workspace layout and visible side panels, switching actual images, slice scrolling, real contrast changes, Blend images with all eligible demo MRI/CT layers, CT overlay opacity measured in rendered pixels, separate 3D opacity measured in rendered pixels, layout changes, restricted edits, cancellation/reset, original recovery/draft/view/history preservation, and the minimum supported window size. The existing planner workflow and packaged planning/evaluation regressions remain applicable.

Testing also found a shared 3D control synchronization bug: programmatic opacity restores updated the renderer but did not update the slider or percentage output. sceneControls.update now reflects the current display values in both. A dedicated regression and the native tutorial test verify that returning from 0% opacity to another lesson restores both the rendered brain and its displayed 100% setting. The floating lesson uses compact navigation so its instructions remain readable at the minimum window size.
