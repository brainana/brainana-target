# CT crown coverage (0.1.82)

The original demo CT was resampled to the MRI field of view, whose superior voxel edge is S = 41.875 mm. This boundary cuts through the CT skull crown. Thresholded CT extraction correctly keeps crop cuts open, so the 3D mesh had an oval opening there even though other displayed slices contained an intact skull outline. This is source-image truncation, not evidence of a missing patch of bone. The problem reproduces with the actual bundled CT and default editor settings.

The demo CT now uses the original published RheMAP registration components: the inverse of NMTv2.0-0.5mm-sym_to_MEBRAINS_affine_0GenericAffine.mat followed, in the published ANTs command order, by NMTv2.0-0.5mm-sym_to_MEBRAINS_1InverseWarp.nii.gz. The nonlinear component has its own spatial domain; using the original components avoids the MRI-sized domain of the precomposed MEBRAINS-to-NMT displacement file. No deformation extrapolation, bone filling or new registration is performed.

The expanded output is 168 × 196 × 140 at 0.5 mm, keeping the original MRI lattice with 20 additional voxels on every side. CT values in the MRI overlap differ from the original composite-warp output by at most 3.6e-11 intensity units. The expanded mapping has no nonpositive Jacobian determinants (range 0.1694–2.9354). Bone at intensity 226 no longer touches any image face. The actual app mesh also has no open edges at the crown under the default smooth threshold workflow. Brain alignment remains the previously checked registration; it does not independently establish skull accuracy.

The editor now identifies which R/A/S crop faces touch retained bone and distinguishes selected crop boundaries from source-image boundaries. The feedback recommends widening an adjustable crop or obtaining wider CT coverage as appropriate. Component cleanup happens before contacts are counted, preventing discarded fragments from creating warnings. These diagnostics apply to thresholded and outer-envelope CT surfaces. Open cuts remain open.

Fresh demo imports use the corrected CT. Existing saved projects retain their embedded images; replacing an existing project's CT requires importing the updated CT and rebuilding its planning surface. No saved project is silently altered. Derivation metadata, references, checksums and the reproduction script are bundled with the source. Reproduction: scripts/expand-demo-ct.py <MEBRAINS-to-NMT-bundle> --ants <antsApplyTransforms>.
