# Early-alpha testing

We are making this app public to share it with adventurous early testers. It is unfinished and has not been validated for surgical decisions. Please help us learn what is useful, what is confusing, and what is missing or unnecessary.

Start with the bundled macaque demo. Try image selection, MRI/CT blending, display controls and Demo tutorials. Compare a planning surface with the source slices. Try a simple target and hardware definition, then manual placement, automatic fitting, grid holes, stereotaxic objects and measurements. Save and reopen a project. If relevant to your work, explore postoperative evaluation.

When something fails, note the exact version and operating system, what you clicked, any error text, and the behavior you expected. Prefer short examples using the bundled demo where possible. General feedback is welcome even when nothing crashes.

Useful questions include: Would you use this feature? Does the order match your workflow? Are the parameter names meaningful? Is there information you need that is not shown? What should be simplified or removed?

The demo CT is an anatomical estimate from a different population template. Brain registration checks do not establish skull accuracy. Hardware envelopes and stereotaxic drawings may simplify actual equipment; consult their linked references and your measurements.
