# Brainana Target documentation

This is early-alpha software shared for exploration and feedback.

- ALPHA_TESTING.md: what to try and how to give useful feedback.
- BUILD.md: development, native packaging, release automation.
- ARCHITECTURE.md: app and shared-package organization.
- VALIDATION.md: checks performed and what they do not establish.
- CHANGELOG.md: this release.

The docs/ directory retains technical notes and design-source references from development. Where an older note describes behavior that has since changed, the current README and this directory take precedence.
